# 🧭 Popsikosland GPS

> **🔐 Пароль налаштувань розробника: `39779567`**


Інтерактивна карта для пошуку маршрутів між точками Popsikosland. Проєкт допомагає прокладати шлях по мережі доріг з урахуванням типу транспорту та обмежень на окремих дорогах.

## ✨ Можливості

- **Пошук маршруту:** вибери початкову та кінцеву точки й побудуй маршрут.
- **Два типи транспорту:** легковий транспорт і вантажівка — кожен використовує дозволені для нього дороги.
- **Типи доріг:**
  - відкрита дорога — доступна для всіх типів транспорту;
  - вузька дорога — лише для легкового транспорту;
  - вантажна дорога — лише для вантажівки.
- **Односторонній рух:** підтримуються дороги з визначеним напрямком.
- **Вибір точки призначення на карті:** клацни правою кнопкою миші або затисни карту на сенсорному пристрої.
- **Позначки країн і міст:** назви показуються залежно від масштабу карти; можна налаштувати розмір кожної позначки окремо.
- **Важливі місця:** для точок можна задати власний колір і символ.
- **Калібрування карти під координати Minecraft:** прив’яжи точки на зображенні до координат X/Z.
- **Редактор точок і доріг:** додавай, змінюй і видаляй елементи мережі.
- **Імпорт та експорт JSON:** перенось дані карти або публікуй оновлену мережу.
- **Світла й темна теми**, анімації та адаптивний інтерфейс для комп’ютерів і телефонів.
- **Змінна ширина бічної панелі:** на комп’ютері перетягуй межу між меню та картою.

## 🚀 Запуск

Проєкт зроблено як вебсторінку без окремого процесу збірки.

1. Завантаж репозиторій або клонуй його:
   ```bash
   git clone <URL-репозиторію>
   ```
2. Переконайся, що поруч із `index.html` лежить файл зображення карти `map.png`.
3. Відкрий `index.html` у браузері або опублікуй файли через GitHub Pages.

> **Важливо:** `map.png` використовується як основа карти. Якщо цього файлу немає або його назва відрізняється, зображення карти не завантажиться. Для повноцінного запуску потрібне підключення до інтернету, оскільки Leaflet завантажується з CDN.

## 📁 Структура файлів

```text
.
├── index.html   # застосунок: інтерфейс, карта та логіка маршрутів
├── map.png      # зображення карти (потрібне для роботи)
├── data.json    # необов’язкові опубліковані дані точок, доріг і позначок
└── README.md    # документація проєкту
```

`data.json` необов’язковий: якщо файл є поруч із `index.html`, застосунок може завантажити з нього опубліковану мережу для відвідувачів без локально збережених змін. Якщо файлу немає, використовуються вбудовані демонстраційні дані.

## 🗺️ Як користуватися

1. Вибери точку **«Звідки»**.
2. Вибери точку **«Куди»**.
3. Обери тип транспорту.
4. Натисни **«Побудувати маршрут»**.
5. Щоб почати заново, скористайся кнопкою скидання маршруту.

Назви точок можна вводити в поля пошуку. Щоб швидко вказати довільне місце на карті, клацни правою кнопкою миші або затисни карту на сенсорному екрані.

## 🛠️ Режим розробника

Режим розробника відкриває інструменти для редагування карти. Він захищений кодом доступу — не публікуй його у README, комітах або відкритих обговореннях.

### Калібрування карти

1. Відкрий **«Калібрування карти»**.
2. Увімкни вибір місця та клацни по впізнаваній точці на зображенні.
3. Введи відповідні координати **X** та **Z** з Minecraft (екран F3).
4. Додай щонайменше дві точки прив’язки, бажано рознесені по карті.
5. Натисни **«Застосувати калібрування»**.

Чим краще розташовані точки прив’язки, тим надійніше можна перевірити відповідність зображення координатам.

### Редагування точок і доріг

1. Відкрий **«Редактор точок і доріг»**.
2. Вкажи назву нової точки та натисни **«Додати точку»**, а потім клацни потрібне місце на карті.
3. Створи дороги між сусідніми точками. Додавай проміжні точки на перехрестях, поворотах і кінцях доріг.
4. Вибери тип дороги та, за потреби, увімкни односторонній рух.
5. За потреби познач точку як службову або як важливе місце.

### Позначки країн і міст

- Створи позначку, клацнувши по карті, або створи її на основі вже наявної точки.
- Вибери позначку в списку, щоб змінити її розмір повзунком.
- Кнопка повернення стандартного розміру відновлює значення за замовчуванням.
- За потреби можна ввімкнути показ усіх позначок незалежно від масштабу.

### Публікація змін для всіх

Дані редактора автоматично зберігаються в локальному сховищі поточного браузера. Це **не оновлює автоматично дані інших відвідувачів**.

1. В редакторі натисни **«Експортувати дані в JSON»**.
2. Збережи експортований файл під назвою `data.json`.
3. Додай або заміни `data.json` у репозиторії поруч із `index.html`.
4. Закоміть і опублікуй зміни.

Інші відвідувачі зможуть завантажити опубліковану мережу, якщо в їхньому браузері немає власних збережених змін.

Для перенесення даних між браузерами використовуй **експорт** та **імпорт JSON**. Імпорт замінює поточні точки, дороги й дані калібрування, тому перед ним варто зберегти поточну версію.

## 💾 Збереження даних

Налаштування теми, анімацій, типу транспорту та дані мережі зберігаються в браузері за допомогою `localStorage`. Вони не синхронізуються автоматично між пристроями чи браузерами. Для перенесення мережі використовуй JSON-експорт та імпорт.

Очищення даних сайту в налаштуваннях браузера може видалити локальні зміни, тому регулярно експортуй важливі дані.
